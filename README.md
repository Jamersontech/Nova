# NOVA

A private AI operating system for James.

NOVA is a long-term system intended to act as an intelligent interface to James's
personal life, businesses, clients, projects, wealth, information, communications, tools,
and workflows.

**Core principle:** Massive capability underneath. Minimal cognitive load above.
